# IP Address Analyzer

A simple web tool for cyber analysts. Runs fully in the browser, no server and no libraries.

## Features
- Validate and classify IPv4 and IPv6 addresses (public, private, loopback, link-local, multicast, reserved)
- Decimal, hex, binary, reverse DNS name, defanged form
- Analyst notes and next-step checklist
- Bulk extractor: pull IPs out of logs, count them, copy as CSV
- Subnet (CIDR) calculator
- One-click links to VirusTotal, AbuseIPDB, Shodan and IPinfo for public IPs

## Run
Open `index.html` in any browser.

## Host free on GitHub Pages
1. Upload `index.html` and `README.md` to a new repository.
2. Go to Settings > Pages.
3. Under Branch, choose `main` and `/ (root)`, then Save.
4. Your site goes live at `https://<your-username>.github.io/<repo-name>/`.
